Сценарий для сверки

Вставь правильный текст речи. Сверка исправляет только обычную речь, сохраняя количество блоков и тайминги. Хайлайты и рукописные акценты не меняются. Вступление вне сценария остаётся на месте.
Фразы и смысловые акценты

Подготовь обычную речь по одному самостоятельному слову и выдели важные темы. Сценарий помогает исправить распознавание. Предложения можно отредактировать до создания графики.

Локальная модель работает на этом компьютере. Аудио и сценарий не отправляются в интернет.

Сначала распознай речь или открой SRT.

Уже созданные клипы можно обновить основной кнопкой внизу, когда проверка текста применена.

Первый расчёт может занять несколько минут. Отключи, если сейчас важнее быстро создать редактируемые клипы.

После создания: один раз рассчитать анимации для воспроизведения. Текст останется редактируемым. После правок расчёт можно повторить.
