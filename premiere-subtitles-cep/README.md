# Субтитры — Artem: 0.6.2 и кандидат 0.6.3

Источник → Текст → Оформление → Сделать субтитры. Выдели один аудиоклип обычной скорости и распознай речь либо открой SRT. Без выделения предложится выбор файла. Сверка со сценарием исправляет только обычную речь, сохраняя хайлайты и время. Перед записью проверь сомнительные слова и прослушай нужные фрагменты.

Создание использует отдельную секвенцию; правки существующего связанного блока записываются без повторного импорта. Не повторяй импорт с неизвестным результатом. Документ панели сохраняется отдельно от записи на таймлайн. Для распознанного файла в новую секвенцию добавляется исходный звук.

Обычная речь — Cera Pro Medium около 55, одно самостоятельное слово сверху справа. Хайлайты — Bebas Neue Cyrillic + Christopher; первая буква рукописной строки заглавная. Кандидат 0.6.3 фиксирует правый край/базовую линию речи и убирает движение/анимационный масштаб, сохраняя короткие клипы видимыми. В исходном checkout ссылки импорта и manifest остаются 0.6.2 до native-проверки.

Для локальной работы нужны Premiere, After Effects для сборки MOGRT, реальные шрифты и отдельные движки Whisper/FFmpeg/Qwen. Они не устанавливаются автоматически этим репозиторием. Пути в transcription-config.json настраиваются под компьютер; используй development-scripts/Настроить локальные движки.ps1 с -EngineRoot из корня распакованного пакета. Пакет кандидата содержит пустые пути вместо путей машины владельца. Распознавание сложной скорости, многоклиповое аудио и другие форматы кадра отдельно не подтверждены.

Переносимая упаковка, проверки и задача исполнителю: [NATIVE-QA-063.md](../docs/NATIVE-QA-063.md). Архив исходников не содержит MOGRT и не является установочным. CEP QA-пакет создаётся только при наличии экспорта 063 Adaptive, согласует все пути шаблона и версии и помечает панель как проверочную. Проверки архива и модель выражений не заменяют реальное изображение/видео в Adobe. Выпуск 0.6.3 ещё не принят.
