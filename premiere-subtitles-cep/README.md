# Субтитры — Artem 0.5.3

1. Выдели аудиоклип на таймлайне и нажми «Распознать» либо открой SRT. Без выделения предложится файл; другой файл доступен в настройках.
2. «Сверить со сценарием» открывает окно для вставки текста. Сверка исправляет только обычную речь, сохраняя хайлайты и тайминги. Затем проверь предложенные фразы; «Прослушать» рядом с временем проигрывает именно этот участок. Исправления текста и ролей сохраняются при повторном открытии панели. При наличии сценария используй сверку; «Смысловые заголовки» выбирают редкие темы локальным ИИ.
3. Нажми основную кнопку «Использовать фразы», затем «Создать … блоков в новой секвенции».
4. Выбери фразу, измени оформление и нажми основную кнопку обновления. Это меняет существующий клип. Правки в панели сохраняются автоматически.

Результат создаётся в отдельной секвенции. Для распознанного файла туда добавляется звук на A1, чтобы проверить синхронизацию. Исходный монтаж сохраняется. После проверки секвенцию можно использовать в монтаже.

Новые заголовки: Bebas появляется первым, затем раскрывается Christopher. Christopher начинается с заглавной буквы; размеры шрифтов рассчитаны отдельно. Речь — Cera Pro. Диагностика и пробный блок находятся в дополнительных инструментах.

Распознавание выполняется на компьютере через whisper.cpp. На текущем компьютере движки установлены. Интернет и платный ключ для работы не нужны. Неуверенные слова и приблизительные тайминги отмечаются при проверке. Сверка со сценарием и выбор тем не заменяют прослушивание.

При восстановлении архива движки остаются в папке проекта `local-ai`, вне ZIP. Если папка перенесена, запусти `development-scripts/Настроить локальные движки.ps1 -EngineRoot "путь к local-ai"`. Описание движков и источников — [local-ai.md](../local-ai.md). Подробности проверки — [release-0.5.3.md](../release-0.5.3.md).

Автоматический захват звука активной секвенции и чтение её captions пока не реализованы: сейчас выбирается аудио/видеофайл. Не все движения из референса воспроизведены; текущий набор — мягкое появление, pop и последовательное раскрытие заголовка.
