# Секреты

**Настоящих секретов в этом файле нет. Сейчас обязательных API-секретов для плагина тоже нет.** Репозиторий публичный; здесь хранится только инструкция.

Когда агент реализует выбранный внешний API, владелец создаёт ключ в кабинете этого сервиса. Для GitHub Actions он добавляет значение в Settings → Secrets and variables → Actions → New repository secret под именем `SUBTITLE_STUDIO_AI_API_KEY`. Для локального плагина значение хранится отдельно на компьютере; GitHub Secret автоматически в Premiere не передаётся.

Секрет передавать только нужному доверенному процессу. В исходниках, скриншотах, архивах версий и логах реальных значений быть не должно. Не выводить ключ в диагностике; проверять только наличие. Не выдавать секрет workflow из недоверенного PR. Если значение оказалось опубликовано, отозвать его у провайдера и заменить; одного удаления файла недостаточно.

`.env.example` содержит только пустые поля. Локальный `.env` и каталоги `secrets/`, `keys/` исключены из Git. Перед архивированием/публикацией проверять содержимое отдельно: .gitignore не защищает произвольный ZIP.

Эта передача не создала настоящий API-ключ, не добавила GitHub Secret и не подключила внешний сервис. Они сейчас не нужны для локального распознавания. Не просить владельца присылать значение в чат.

[Официальная инструкция GitHub](https://docs.github.com/en/actions/how-tos/write-workflows/choose-what-workflows-do/use-secrets).
