# Ключи и подключения

Сейчас ничего покупать или вставлять не нужно. Автоматическое распознавание работает локально через whisper.cpp, обработка тем — через llama.cpp. Действующие модели/пути описаны в [local-ai.md](local-ai.md) и [архитектуре](docs/ARCHITECTURE-AND-SETUP.md). Это не внешние API и ключи им не нужны.

Доступ Codex к GitHub и инструменты текущей сессии настроены в приложении. Пароли, токены и внутренние доступы сессии сюда не переносить. Подключение GitHub-агента настраивается в его приложении отдельно; AGENTS.md описывает работу, но не выдаёт доступ.

Если внешний ИИ улучшит результат, агент должен сначала выбрать подходящую задачу и сервис, проверить доступность, стоимость/лимиты и передачу данных, затем реализовать и проверить интеграцию. Не обещать бесплатный безлимитный API без подтверждения. Сохранить рабочий локальный вариант.

Для будущей интеграции зарезервированы имена:

| Имя | Где хранить | Что означает |
|---|---|---|
| SUBTITLE_STUDIO_AI_PROVIDER | Обычная настройка | Выбранный провайдер |
| SUBTITLE_STUDIO_AI_BASE_URL | Обычная настройка | Адрес API |
| SUBTITLE_STUDIO_AI_MODEL | Обычная настройка | Идентификатор модели |
| SUBTITLE_STUDIO_AI_API_KEY | Секрет | Ключ, выданный провайдером |

[.env.example](.env.example) — пустой проектный шаблон, не действующая конфигурация текущего плагина. Эти имена ещё не читает runtime. Не объявлять внешний API подключённым по наличию файла. Ключ не заменяет авторизацию GitHub и не управляет локальным Premiere.
