# Версия 0.5.0 — 12 октября 2026

Установлена в настоящем Premiere 26.2.0. Добавлено локальное автоматическое распознавание аудио и видео из панели, подготовка читаемых фраз и новая последовательная анимация составного заголовка. Основная кнопка сначала применяет проверенный текст, затем создаёт отдельную секвенцию, после создания обновляет выбранный клип.

## Реализовано

- whisper.cpp large-v3-turbo запускается отдельным скрытым процессом. Выбор WAV/MP3/M4A/MP4/MOV и других поддерживаемых файлов, русский/авто/английский, прогресс, отмена, восстановление задания после открытия панели. Исходный документ сохраняется до применения результата, прежний набор можно вернуть.
- Обычные слова объединяются в фразы. Длинные блоки автоматически делятся без потери слов и оформления. Точные словесные метки сохраняются, приблизительные тайминги обозначаются. Отдельный сценарий позволяет исправить распознавание перед созданием.
- Локальный ИИ запускается из панели для выбора редких тематических заголовков. Добавлена проверка грамматической формы предложенных заголовков. Предложения показываются до применения.
- Шаблон 050: Bebas раскрывается первым, Christopher — следом; отдельные измерительные слои сохраняют размеры при анимации. У Christopher первая буква заглавная, остальные строчные; пропорции шрифтов рассчитаны отдельно. Добавлена тень и лёгкий подъём при мягком появлении. Старые клипы с прежним шаблоном сохраняются.
- Звук распознанного файла добавляется на A1 собственной новой секвенции для проверки таймингов. Неудача добавления звука не отменяет подтверждённые субтитры. Исходный монтаж не меняется.

Секвенция `[Subtitle Studio] SRT 1791827116366`, ID `3be7cd2c-51b0-426d-a00c-0e04654658f8`. Текст, шрифты и кадрованные тайминги всех клипов прочитаны обратно. На A1 один исходный аудиоклип, видео не изменено.

Экспортированы 34 кадра: видимый текст и эффекты внутри безопасной зоны. Проверены четыре кадра анимации: пустое начало, частичное раскрытие Bebas без Christopher, затем частичное раскрытие Christopher, полный заголовок. Основная кнопка обновила размер существующего блока 11 до 105% и вернула 100% без нового импорта. Проект сохранён, исходная секвенция сохранила 96 видео- и 26 аудиоклипов.

Отдельно распознан MP4 из папки «Примеры», отмена во время декодирования проверена; промежуточный WAV удаляется. ## Практические ограничения

Звук выбирается из файла, автоматический экспорт аудио активной секвенции пока не реализован. Шаблон ориентирован на вертикальный кадр 1080×1920. Новые движения доступны новой секвенции с шаблоном 050. Сейчас воспроизведены ключевые принципы образца, а не весь каталог анимаций. Машинное распознавание и выбор тем могут ошибаться; финальная оценка синхронизации и оформления человеком ещё требуется. Кириллица в имени пользователя Windows для временных путей отдельно не проверена.

Движки и модели остаются в папке local-ai вне ZIP. Инструкции восстановления в local-ai.md. Пользовательские шрифты и шаблоны из recovery-inputs предназначены только для локального восстановления; не публиковать архив как публичный дистрибутив.
