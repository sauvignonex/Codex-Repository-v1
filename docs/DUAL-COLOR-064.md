# Отдельный AE-кандидат 064: цвета строк

В референсном рилсе встречаются красный/белый и жёлтый/белый акценты. Общий цвет блока 062/063 не позволяет воспроизвести их независимо. Подготовлен **только исходник отдельного AE-кандидата**, не установленный MOGRT и не законченная функция панели.

`development-scripts/build-vertical-template-064.jsx` создаёт `Subtitle Studio Vertical 064 Dual Color` в собственной AE-копии. Слои, одобренные шрифты, 145/130, позиции, duration, motion blur, reveal и неподвижная речь сохраняются из 063. Первые семь effects и их значения прежние. В конец добавлены:

| Effect | Параметр | Default |
|---|---|---|
| 8 | Раздельные цвета строк | 0 — выключено |
| 9 | Цвет основной строки | Белый |
| 10 | Цвет рукописной строки | Белый |

При 0 общий «Цвет» действует на все слои. При 1 Bebas берёт effect 9, Christopher — effect 10, а обычная речь сохраняет общий цвет. Кандидат не навязывает цвет всему набору и не меняет его текст/время. Переключатель выключен по умолчанию, поэтому прежний вид сохраняется.

## Проверки

`node development-scripts/test-dual-color-template.cjs`: 6 групп проверок модели выражений, порядок/default первых семи контролов, общие/независимые цвета, белый/жёлтый вариант и сохранение font/normal caps. Геометрия, opacity, timing и mask-выражения сравниваются побайтово с 063. VM-fixture не экспортирует настоящий AE-проект.

Native-приёмка открыта:

1. На собственной пустой AE-копии запустить build-vertical-template-064.jsx; проверить SUCCESS/EXPORT true в template-build-064.txt. Не запускать на чужом проекте и не заменять импортированные клипы.
2. Запустить check-dual-color-064.jsx в этой копии. Проверяются цвета/шрифты для всех ролей; все изменённые controls восстанавливаются в finally, проект не сохраняется. Проверить dual-color-native-064.txt.
3. В отдельной Premiere-секвенции вручную проверить выключенный режим против 063 и включённые красный/белый, белый/жёлтый варианты. Снять движение, pause и реальную читаемость на фоне; сравнить с рилсом и прежними размерами. Проверить речь и короткие клипы отдельно.
4. Только после native-проверки подготовить явное подключение панели: значения по каждому блоку, сохранение после reopen, прежние документы без новых полей, guard/applied-signature, protected highlight correction, writer/preflight и QA-упаковка нужного шаблона. Это ещё не реализовано.

Пути runtime и source/QA-пакет 063 остаются прежними. Архиватор 063 не принимает 064 вместо 063. Шаблон 064 ещё не экспортирован, локально не установлен; по цветам в реальном Adobe результат не подтверждён.
