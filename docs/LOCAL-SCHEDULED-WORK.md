## Один writer

Перед изменением кода/Adobe ручной и плановый исполнитель берёт один общий lock вне Git. Команда (использовать доступный Python):

`python development-scripts/local-work-lock.py acquire --path "D:/Projects Adobe/Разработка плагина/.subtitle-studio-state/writer.lock" --owner "01a12fd6-2d77-75c3-bde7-50dfc9cf881d"`

Сохранить returned token только локально. Если acquired=false/exit 3 — не менять файлы/Adobe, не создавать другого исполнителя. Не снимать stale lock автоматически: сначала проверить статус владельца и незавершённую native-операцию. Это кооперативная защита, а не обещание защиты от посторонних процессов, которые её не используют.

В finally после завершения/проверки native-операции:

`python development-scripts/local-work-lock.py release --path "D:/Projects Adobe/Разработка плагина/.subtitle-studio-state/writer.lock" --owner "01a12fd6-2d77-75c3-bde7-50dfc9cf881d" --token "TOKEN_FROM_ACQUIRE"`

Освобождение с чужим token запрещено. Не держать lock в ожидании художественного ревью; при неизвестном результате операции сохранить lock/receipt и явно остановить зависимую работу. Кодекс-настройки/секреты/живые документы/lock token в GitHub не публиковать.
