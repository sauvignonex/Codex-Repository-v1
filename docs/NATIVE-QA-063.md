# Кандидат 0.6.3: неподвижная речь

13 октября 2026. Исходники подготовлены; не проверено в Adobe. Установленный 062 и исторические отчёты не заменены. Новый MOGRT не создан: облачная среда не содержит Adobe. Локальные движки, живой документ, preview-кэш и каталог «Версии» владельца здесь недоступны.

## Изменение

Речь: правый край видимых букв 964 px, базовая линия 375 px при «Высота» 50 (1080×1920). Высота смещает базовую линию с ограничением 315…1100, независимо от формы букв. AE anchorPoint — `[rect.left + rect.width, 0]`, Position задаёт край и базовую линию. Масштаб подгонки текста сохраняется, анимационный scale/lift/blur убраны. До 100 мс включительно opacity=100%; длиннее — короткая прозрачность. Текст, длительность и границы не переписываются.

Предпросмотр измеряет CSS-базовую линию и правый край букв, включая замену отсутствующего шрифта. Хайлайты используют прежние выражения. Browser и модель AE проверены; совпадение реальных рендеров ещё предстоит подтвердить.

## Доступные проверки

Из корня репозитория, Node.js и установленный `playwright`:

```sh
node development-scripts/test-stationary-speech.cjs
node development-scripts/test-phrases.cjs
node development-scripts/test-motion-quality-062.cjs
python development-scripts/test-package-candidate.py
```

При необходимости `SUBTITLE_PLAYWRIGHT_MODULE` указывает на установленный модуль Playwright, `SUBTITLE_CHROMIUM` — на Chromium. Тест поднимает временный HTTP-сервер на loopback и закрывает его. Результат — `premiere-subtitles-cep/stationary-speech-tests.json`. Модель выражений не запускает AE. Browser использует `recovery-inputs/fonts/CeraPro-Medium.ttf`, уже присутствующий в репозитории; это не установка шрифта владельцу.

## Задача локальному исполнителю

1. Сохранить живые проект, документ панели и связь. Открыть собственный отдельный пустой AE-проект; не закрывать чужой открытый проект ради теста.
2. Запустить `development-scripts/build-vertical-template-063.jsx` через File → Scripts → Run Script File. Пути берутся относительно файла в репозитории. Проверить `template-build-063.txt`: SUCCESS, корректные шрифты и EXPORT true. Результат: собственный `Subtitle Studio Vertical 063 Adaptive.mogrt` и AEP; при повторе duplicate guard останавливает сборку.
3. Запустить `check-stationary-speech-063.jsx`: проверить SUCCESS в `stationary-speech-native-063.txt`. Скрипт временно меняет только параметры/текст собственной comp 063 и восстанавливает их в finally, не сохраняет проект. Он проверяет геометрию и expressionError; не доказывает видео.
4. В отдельной тестовой секвенции Premiere импортировать 063. Проверить подряд «и», «лес», «баня», «мёд», «где», «скрабирование», «пихтового» при одинаковом оформлении, все режимы и исходные 60 мс. Записать видео стыков и измерения края/базовой линии; сравнить с референсом. Проверить реальные Cera/Bebas/Christopher, безопасную зону, тени и отсутствие сдвига. Проверить хайлайт «КЕДРОВАЯ / Бочка»: прежние пропорции и темп.
5. Для согласованного CEP QA-пакета использовать сборщик ниже: он переключает четыре пути в `test-graphic.jsx` и `batch.jsx`, а также manifest/index/host-loader только внутри архива. Исходники 062 и предыдущая установка сохраняются. Не объявлять preview новой версией установленных клипов: новый файл не обновляет старый MOGRT на таймлайне.
6. Создать отдельный полный набор, сохранить прежнюю секвенцию; сравнить все тексты/границы/хайлайты и исходный звук. Проверить кэш каждого клипа, восстановление In/Out и воспроизведение всего набора. Сохранить native-логи/видео, выпуск и предыдущую версию по правилам AGENTS.md.

P0 остаётся открытой до пунктов 4–6. Не публиковать новый выпуск и не переносить пользовательское одобрение 062 на этот кандидат.

## Переносимая сборка

Пакет исходников можно создать без Adobe:

```sh
python development-scripts/package-candidate.py --output dist/Subtitle-Studio-0.6.3-source.zip
```

Он содержит код, сборщик, тесты, требования и инструкцию продолжения. Не содержит MOGRT, пользовательских медиа, проектов, шрифтов, моделей или секретов. Для браузерного теста нужен Cera в указанном тестом пути либо полная копия репозитория. Это не установочный пакет.

После настоящего экспорта из AE:

```sh
python development-scripts/package-candidate.py --template "premiere-subtitles-cep/templates/Subtitle Studio Vertical 063 Adaptive.mogrt" --output dist/Subtitle-Studio-0.6.3-cep-qa.zip
```

QA-пакет проверяет структуру/метаданные MOGRT, параметры и шрифты; это не доказательство изображения. Синтетическая фикстура теста упаковки не является Adobe-проектом и не включается в итоговый пакет. Индекс панели помечен «проверка», `native_verified=false`. Сборщик согласует все четыре пути импорта и версию загрузчика JSX. Старый 062, отсутствующий экспорт и неправильные параметры останавливают сборку до создания архива.

В каждом архиве — SHA-256/размер каждого файла в `candidate-manifest.json`; содержимое проверяется чтением ZIP обратно. Существующий архив не перезаписывается. Запускается из любой рабочей папки: пути исходников определяются относительно скрипта. Настройки движков содержат пустые пути: после распаковки настроить их штатным PowerShell-скриптом с `-EngineRoot`. Для собственного QA-пакета можно передать уже настроенный локальный файл через `--engine-config`; такой пакет содержит машинные пути. Локальные установка, сохранение каталога «Версии» и запуск Adobe автоматически не выполняются.
