# Умный стиль выбранного блока — кандидат

Проблема: роль, анимация, размер и положение были отдельными элементами интерфейса. «Авто» считало любое одно/два слова заголовком — это особенно неверно для обычной речи по одному слову.

Теперь на основном экране одна кнопка **«Настроить стиль блока»**. Она открывает рекомендацию с причиной и действием «Подобрать для этого блока». Ручные роль/появление/размер/цвет находятся внутри «Уточнить вручную». Речь имеет отдельную понятную настройку «Показывать сразу, без затухания»; неподвижность остаётся обязательной.

## Как подбирается стиль

- Уже определённые заголовки и рукописные акценты сохраняют роль и одобренные пропорции; модель не переопределяет их при открытии настроек.
- Обычная речь/неопределённый блок может получить предложение локальной модели по тексту блока, исходной речи, длительности и двум соседним блокам с каждой стороны. Запрос идёт только в существующий loopback API. Новые модели, медиа и облачный API не добавлены.
- Модель возвращает только роль, уверенность и краткую причину. Проверяется формат ответа; confidence менее 0.8 не используется (это самооценка модели, не измеренная точность). При соседнем хайлайте или длительности менее 250 мс новое семантическое повышение роли не предлагается.
- Если модель недоступна/ответ некорректен, интерфейс остаётся рабочим. Локальные правила сохраняют известную роль, используют короткую пару строк как структурный сигнал, а одиночное слово считают речью. Семантическое решение по одному только текстовому шаблону не объявляется ИИ-анализом.
- Речь: короткое затухание без перемещения/масштабирования; 60 мс остаются полностью видимыми. Хайлайты: последовательное раскрытие; менее 250 мс — сразу без анимации. AE-выражения и одобренный темп 062/063 не переписаны.

## Границы записи

Открытие настроек и получение предложения не меняют документ. Применение меняет только role/motion выбранного блока, сохраняя его текст, исходную речь, words, start/end, цвета/размеры/позицию и соседние блоки. Есть отмена последнего подбора. Смена блока закрывает редактор и отменяет устаревший анализ. Ручная правка роли/текста отменяет старое предложение. Никакой записи в Premiere при этих действиях нет: существующая явная запись выполняется на последнем шаге.

Окно анализа ограничено 15 секундами; отмена закрывает ожидание/запрос панели, но не убивает общий сервис модели. Качество смысла зависит от установленной модели и контекста; предложения могут требовать ручной правки.

## Доказательства и открытые задачи

`test-smart-style.cjs`: браузер/подставной ответ модели, сохранность времени/слов/соседей, отмена, reload, invalid/low-confidence/offline, поздний ответ, узкие панели и клавиатура. Скриншоты: `dist/visual-review/smart-style-*.png` (CI artifact). Старые stationary/visual/update проверки остаются обязательными.

**Не подтверждены:** качество реального семантического выбора локальной модели на пользовательском ролике, native-изображение/видеопоявление, полное сходство с референсом и полный кэш. Панель не установлена владельцу. Следующая художественная задача — реальная проверка предложений и движения по референсу; дальнейшее упрощение должно учитывать результат, а не число зелёных тестов.
