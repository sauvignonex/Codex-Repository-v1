## Очередь

1. **P0: неподвижная обычная речь сверху справа.** Правый край/базовая линия не меняются при разной длине/выносных буквах. Убрать lift/pop/scale речи, допустима прозрачность. Короткий клип не должен стать невидимым; «где» исходно 60 мс, не удлинять молча. Хайлайты/время сохранить.
2. **P1: художественная доводка хайлайтов по рилсу.** Последовательность строк, оправданные акценты/цвет/blur, резкая пауза. Сохранить пропорции/адаптивность.
3. **P1: update и надёжная запись.** Правка связанного клипа без импорта, понятные ошибки/связь, нет дубликатов.
4. **P2: точность транскрипции/тем.** Прослушивание, конкретные сомнения, защищённая сверка, синхронизация на слух. Не выдумывать имена.
5. **P2: переносимость.** Отдельная настройка машинных путей и тестов, исторические доказательства сохранить. Native только на своей копии.
6. **P2: производительность.** Полный набор/кэш/отмена/восстановление диапазонов, не возвращать измерительные дубликаты.

## Не подтверждено

Полное художественное совпадение; FPS/плавность полного незакэшированного набора; многоклиповое распознавание, микшер/эффекты/сложная скорость; другие кадры/платформы/версии; автоматическая связь GitHub с локальным Codex. 0.6.3 ещё нет. Передача материалов не запускала native-импорт или рендер; локальная разработка была поставлена на паузу.
