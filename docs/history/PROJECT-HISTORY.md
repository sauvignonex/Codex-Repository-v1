## Развилки

- Просьба перенести все субтитры вниз отменена словами «пока не надо». Картинка с кругом — история, не текущая координата.
- Критика слов без тем не отменяет последующее правило одного слова для обычной верхней речи: это разные роли.
- Captioneer, готовые скрипты и бесплатный API — необязательные ориентиры. Выбраны локальные движки.
- Уже открытый AE не перезапускать; native-проверку вести в своей копии, не трогая чужой монтаж.

Оригинальные release-*.md, requirements-history-before-0.4.1.md, plugin-requirements.md и development-checkpoint.md сохранены в корне. Они описывают исторические состояния; актуальные требования — AGENTS.md, актуальные данные — живой документ.
