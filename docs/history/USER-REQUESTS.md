# Исходные пожелания пользователя

Подборка существенных формулировок в порядке обсуждения, не полная стенограмма. Точные времена не приписываются без источника.

| Сообщение | Действующая трактовка |
|---|---|
| «пересохранять версии, старую и новую ... и список требований» | Две версии выпуска, требования и продолжение рядом. |
| «не работает ... если нужно переделай» | Разрешена переработка механизма ради реального результата. |
| «Christofer ... с большой буквы ... маленькими» | Christopher sentence case, caps выключены. |
| «при одинаковых значениях scale ... разные размеры ... соблюдать пропорции» | Размеры по реальным буквам, отдельный размер акцента. |
| «вторая строчка ... не кристофер ... бебас» | Проверять шрифты на изображении, не только JSON. |
| «шрифт увеличь нижний» → «вот теперь заебись» | Увеличенный Christopher 0.3.7 — одобренный ориентир. |
| «неинтуитивный интерфейс ... ненужных кнопок» | Понятный основной путь и минимум служебных кнопок. |
| «внедрить автоматическую транскрипцию» | Распознавание обязательно, SRT не единственный вход. |
| «выделил аудиодорожку ... должно было заработать» | Учитывать выделенный клип/обрезку/позицию. |
| «окошко ... сценарий ... не нарушая тайминги» | Отдельная сверка, границы сохраняются. |
| «не менял хайлайты ... только обычные слова» | Защищать title/accent целиком. |
| «нормальный дизайн. человеческий ... референсы ... примеры» | Референсы и результаты дизайна сохраняются. |
| «область не двигалась когда я скролю ... меньше» | Компактная sticky-шапка/этапы. |
| «в конце ... сделать субтитры ... слева направо» | Финальный шаг с явной кнопкой создания. |
| «анимации ... как в примере ... motion blur ... масштаб» | Сравнивать движение с рилсом, резкая пауза чтения. |
| «обычный текст ... сверху справа ... cera pro medium» | Координаты относятся только к речи, не ко всем акцентам. |
| «максимум одно слово ... предлоги ... два, ... три ... два обычных ... нельзя» | Одно самостоятельное слово плюс служебные токены. |
| «размер ... 55 ... только ... обычных ... сверху справа» | Не распространять 55 на крупные хайлайты. |
| «таймлайн лагает ... i5 12400f 32gb ddr4 и 4060» | Проверка полного набора и производительности. |
| «Да, теперь плавно» | Полный 061 после кэша, не любой будущий шаблон. |
| «Темп подходит» → «подстраиваться под длину слов» | Сохранить ориентир и адаптировать, не менять SRT. |
| «слова прыгают ... ровно стояли ... сверху справа» | Самая свежая нерешённая задача. |
| «только важные вопросы», «продолжай без меня» | Автономность в разрешённых границах; при зависимости сохранить состояние. |
| «на паузу ... перезагружу чат гпт» | Явная пауза локальной разработки. |

Полный исходный сценарий в [examples/scenario-original.txt](../../examples/scenario-original.txt). Опечатки «борятмя»/«омолажения» сохранены как слова владельца, не программная норма. Аудио содержит дополнительное вступление про баню/духов: сценарий нельзя считать дословным эталоном всей записи. Правильное написание имён духов отдельно не подтверждено.
