# 0.4.3 — интерфейс и восстановление после изменения клипов

Установлена в открытую панель Premiere 12 октября 2026 года. Основная кнопка выбирает действие по связи текущего SRT: создание отдельной секвенции либо обновление выбранного существующего клипа. При связанном наборе доступна дополнительная «Новая секвенция». Диагностика, пробный блок и подготовка текста свёрнуты; убраны дублирующие основные действия, ручное сохранение и недоступный источник аудио. Правки сохраняются автоматически. Шаблон 043 и одобренные пропорции не менялись.

Причина блокировки на скриншоте: прежний пакет подтверждён (29 из 29), но его клипы изменены. Новый документ содержит 28 фраз. Раньше отказ до начала создания стирал подтверждённую локальную связь и оставлял ложный pending intent. Теперь подтверждённый изменённый/удалённый пакет допускает создание отдельной новой секвенции. Обновление повреждённого набора запрещено. Неизвестный результат настоящего импорта по-прежнему нельзя повторять. Проверка источника, шаблона и пресета выполняется до сброса старой связи.

Проверка настоящего Premiere: восстановлена подтверждённая история из живого JSX, native verifyBinding=changed, prepareBegin=ok; новая основная кнопка доступна. Документ ed35533a-a898-4e50-9eb0-e3122ff3bba7, 28 фраз сохранены. Попытка создания обнаружила блок 18 («вещества кедра отлично борются с вирусами и бактериями.»): расчёт даёт 44.43 px при минимуме 45. Импорт не начался, набор и native registry не изменились. Теперь причина видна у основной кнопки и панель сразу выбирает блок 18. Создание всех 28 клипов на этой версии НЕ подтверждено: сначала нужно разделить/сократить эту фразу. Текст автоматически не переписывался, тайминги не менялись.

Проверки: 31 сценарий host/графики, 13 рабочего интерфейса, 3 восстановления client/native состояния, 18 SRT, 8 CEP; все прошли. Новые регрессии проверяют изменённые клипы, отказ preflight без потери registry и блокировку неизвестного результата импорта. Отчёты recovery-native-0.4.3.json, validation-native-0.4.3.json и recovery-test-results.json находятся в premiere-subtitles-cep. Превью интерфейса — visual-check-0.4.3.

Следующий этап: дать удобное разделение длинной фразы с явной проверкой приблизительного тайминга, затем проверить полный актуальный набор и обновление клипа на реальном таймлайне. Не сбрасывать документ к старым 29 фразам. Распознавание из панели, размещение поверх монтажа и визуальная проверка синхронизации остаются незавершёнными.
