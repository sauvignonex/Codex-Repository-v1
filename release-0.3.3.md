# Версия 0.3.3 — 12 октября 2026

Подтверждено создание одного редактируемого MOGRT в реальном Premiere 26.2.0. Пользователь подтвердил видимость слова «Традиционная» в Program.

## Изменения

Постоянные объекты JSX теперь хранятся на `$`: `$._artemSubtitleStudio` и `$._artemSubtitleTest`. Это устраняет зависимость от области видимости `evalFile`. Клиент вызывает функции через обёртку try/catch и показывает этап и строку ошибки.

Реальный запуск выявил `Illegal Parameter type` на `setLocked(false)`. Вместо клонирования и очистки монтажа новая реализация создаёт пустую вертикальную секвенцию из штатного `Social Media Portrait 9x16 30 fps.sqpreset` через `qe.project.newSequence`, как в примере Adobe PProPanel. Это исключает перенос исходных captions, которые недоступны для очистки через обычный CEP DOM. Частота кадров сверяется с исходной секвенцией.

Повторное открытие панели находит созданный клип в текущем ExtendScript-контексте. Кнопка «Обновить пробный блок» записывает текст в тот же клип, не импортируя второй MOGRT. Защита не является постоянным журналом между запусками Premiere.
