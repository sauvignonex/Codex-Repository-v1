# Шаблоны Reels и SaaS

Версия 0.3.3: один SaaS Pack Title 07 импортирован в пустую секвенцию 1080×1920 в настоящем Premiere. Поле текста найдено под индексом 7, записаны «Традиционная» и BebasNeueCyrillic; пользователь подтвердил видимость текста. Подробности — release-0.3.3.md. Следующий этап — масштаб/положение, безопасная зона, анимация и длительность по SRT.

Найдены 46 установленных MOGRT: 28 Reels Text Animation и 18 SaaS Pack Title. Названия всех встречаются в XML проекта «Рилс Колобки»; это не подтверждает использование каждого на финальном таймлайне. Пользователь одобрил оба набора. Исходные шаблоны не изменены; полный список параметров и путей сохранён в template-inventory.json.

Предварительное назначение SaaS по параметрам (анимация ещё требует просмотра):

| Шаблоны | Кандидат на использование |
|---|---|
| 01–04, 06, 08, 14–16 | Составные заголовки с двумя текстовыми полями |
| 07 | Простые одночастные блоки |
| 05, 09 | Смысловой акцент: отдельное поле Special Word |
| 12, 17 | Печатание текста; доступны скорость и управление курсором |
| 18 | Одно текстовое поле с копиями для эффекта |
| 10 | Семь текстовых полей; нужна отдельная проверка ограничения двух строк |
| 11, 13 | Счётчики; только для подходящих числовых фрагментов |

У SaaS исходный кадр 3840×2160. Простое копирование координат в вертикальный кадр не подходит. Перед автоматическим применением проверить длительность входа/выхода, замену шрифта на Bebas/Cera/Christopher, границы всех копий текста, свечения и размытия во время анимации. Наличие редактируемых полей в definition.json не подтверждает успешную запись через API Premiere.

Порядок подключения: пробный блок на отдельной тестовой секвенции → чтение и изменение реальных параметров → проверка кадра и анимации → сохранение и повторное открытие → пакетное создание из SRT. Не применять сразу ко всему исходному монтажу.
