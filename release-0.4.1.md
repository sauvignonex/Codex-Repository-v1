# Версия 0.4.1

После жалобы на одиночные слова, ошибки и неработающее обновление переработана подготовка текста. Из 114 исходных реплик сделаны 29 фраз. Сценарий пользователя восстанавливает кедровую бочку, скрабирование, пихтовое масло и другие пропущенные слова. Начало отдельно перепроверено по исходному аудио; написание Монча-кува/Монча-кугыза сверено с [музейной публикацией](https://fumus.ru/upload/medialibrary/bdd/om4gfz0jb555blrb2efj4d6san0zw3ul.pdf). Предложения тем получены через реальный локальный API из CEP-панели.

Подготовка сохраняет оригинал и показывает изменённые фразы перед применением. Новые фразы имеют отдельный UUID и требуют новой секвенции. Повторное открытие идентичного исходного SRT сохраняет правки и связь с клипами. Подтверждённые клипы частичного пакета можно обновлять, а после остановки на границе блока — создавать отдельный новый пакет; неизвестный результат импорта остаётся заблокированным. Исправлено включение кнопки до восстановления сохранённого реестра.

Заголовки в проверенной секвенции: «Кедровая / Бочка», «Мягкое / Скрабирование», «Пихтовый / Массаж». Обычная речь — Cera Pro Medium, заголовок — Bebas, дополнение — Christopher с первой заглавной и остальными строчными. Переносы для речи рассчитаны общей функцией для предпросмотра и записи в MOGRT. Масштабирование остаётся пропорциональным.

Локальный API работает без оплаты за запросы и дневной квоты, пока работает компьютер и запущен процесс. Модель не получает инструменты, не пишет JSX и не меняет тайминги. Первые попытки автоматического переписывания фраз моделью дали плохой результат и не записывались в Premiere. Финальный алгоритм сверяет текст со сценарием; модель предлагает только отдельные заголовки. Неудачные предложения фильтруются. См. local-ai.md.

## Проверка

- 27 проверок графики и защиты импорта, 18 SRT, 8 CEP, 9 подготовки фраз.
- Реальные обновления подтвердили изменение роли, Christopher и масштаба существующего клипа; клипов осталось 3 в старом частичном пакете. Исходное оформление восстановлено.
- Все 29 клипов новой секвенции проверены по текстовым полям, шрифтам, Small Caps, роли, длительности и границам до кадра. Затем две соседние фразы уточнены через кнопку обновления без новых клипов: предлог «с» перенесён к «вирусами и бактериями».
- Экспортированы реальные PNG в Premiere по [примеру Adobe](https://github.com/Adobe-CEP/Samples/blob/master/TypeScript/PProPanel-vscode/dom_app/src/Premiere.jsx). На всех 29 кадрах текст виден и находится внутри пользовательской безопасной зоны. Несколько кадров дополнительно просмотрены вручную.
- Установка проверена по SHA-256 для 23 файлов. Проект сохранён по известному пути тестового проекта; оригинальная последовательность не изменялась этими операциями.

Артефакты: premiere-subtitles-cep/premiere-batch-0.4.1.json, premiere-update-0.4.1.json, editorial-test-results.json, installation-0.4.1.json; visual-check-0.4.1/geometry-report.json и frame-*.png; исправленный SRT, сценарий и оформленный документ в recovery-inputs/editorial.

## Осталось

Новый результат ещё не оценён пользователем. Проверены кадры в середине клипов; сложные анимации по образцу ещё не реализованы. Используется одобренный шаблон 040 с обычными soft/pop. Свободное распознавание аудио из панели, пословная подсветка и перенос на исходный монтаж остаются следующими этапами.

После сохранения 0.4.1 удалось связаться через BridgeTalk с уже открытым After Effects и экспортировать отдельный прототип 042 без запуска и закрытия редактора. Прототип не прошёл визуальную проверку: маска раскрытия обрезает Christopher, контрольный полный кадр теряет первую строку. Он не установлен и не включён в шаблоны рабочей панели. Нельзя считать его готовой версией 0.4.2. См. development-checkpoint.md. Работа приостановлена до возвращения пользователя для оценки нового результата 0.4.1; фоновых циклов ожидания нет.
