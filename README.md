# Subtitle Studio — субтитры для Premiere

Рабочие исходники и история разработки плагина Артёма. Цель — автоматически распознавать речь, проверять её и создавать редактируемые анимированные субтитры в стиле референсного рилса, различая обычную речь и крупные смысловые хайлайты.

**Состояние: 0.6.2, 103 блока, полный preview-кэш проверен. Следующий дефект — скачки обычных слов сверху справа. Исправление 0.6.3 ещё не внесено.**

## Состав

- `premiere-subtitles-cep/` — текущая панель, JSX-хост, MOGRT и отчёты.
- `development-scripts/` — проверки и сборщики AE. Не запускать все исторические repair-скрипты подряд.
- `release-*.md`, `plugin-requirements.md`, `development-checkpoint.md` — оригинальные документы развития, с историческими состояниями.
- `visual-check-*` — контрольные изображения разных этапов.
- `recovery-inputs/` — снимки документов/проектов и собственные AE-исходники. Не восстанавливать поверх живого документа автоматически.
- `docs/history/screenshots/` — 21 исходный скриншот владельца: ошибки, пожелания и одобренный вид.
- `examples/` — референсы, звук/SRT, сценарий и тестовый Premiere-проект.
- `docs/MATERIALS-MANIFEST.json` — размеры/SHA-256 перенесённых файлов.
- `docs/EXTERNAL-MATERIALS.json` — сторонние пакеты, оставшиеся локально; они не выданы за наши разработки.

## Актуальные правила

Обычная речь: Cera Pro Medium около 55, одно самостоятельное слово, сверху справа, неподвижная строка. Хайлайты: Bebas + Christopher, одобренные пропорции, Christopher с первой заглавной и остальными строчными. Сверка сценария меняет только речь, не хайлайты и не время. Эти правила имеют приоритет над старым требованием объединять всю обычную речь во фразы.

GitHub не даёт автоматически доступ к запущенным Adobe владельца. Тесты/JSON не заменяют native-проверку. Отчёты — доказательства прошлых запусков, не результат нового CI.

Полная стенограмма ответов ассистента не экспортировалась. История восстановлена из доступных пользовательских сообщений, оригинальных release-заметок, скриншотов, кода и отчётов. Неизвестные подробности не выдумывались.
