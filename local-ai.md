# Локальные движки — 0.5.0

Распознавание запускается самой панелью, без сервера: CEP → отдельный Python-процесс → FFmpeg → whisper.cpp large-v3-turbo. Исходный файл не изменяется. Отмена завершает дочерний процесс; промежуточный WAV удаляется. JSON, SRT и журнал остаются в пользовательской папке `SubtitleStudio/jobs` для проверки и восстановления. Панель продолжает следить за тем же заданием после повторного открытия.

Движки находятся в `D:/Projects Adobe/Разработка плагина/local-ai`, вне резервного ZIP. Конфигурация: `premiere-subtitles-cep/transcription-config.json`; для нового пути используйте `development-scripts/Настроить локальные движки.ps1 -EngineRoot "путь"`. Не удалять папку local-ai при восстановлении плагина.

Источники:
- whisper.cpp, MIT: https://github.com/ggml-org/whisper.cpp — Windows CUDA 12.4, release b5454. URL и проверенный SHA-256 архива в `local-ai/transcription-runtime.json`.
- Whisper large-v3-turbo: https://huggingface.co/ggerganov/whisper.cpp — ggml-large-v3-turbo.bin. Русский язык по умолчанию, автоматическое определение и английский доступны в настройках.
- Python 3.12.10 embeddable: https://www.python.org/downloads/release/python-31210/ — лицензия PSF, LICENSE.txt в папке Python.
- FFmpeg 7.1 gyan.dev essentials, GPL v3+: https://www.gyan.dev/ffmpeg/builds/ и https://ffmpeg.org/legal.html. Копия из imageio-ffmpeg; SHA сохранён. FFmpeg и его двоичные файлы не распространяются в ZIP плагина.

Смысловые заголовки: локальный llama.cpp + Qwen3-4B-Instruct-2507-Q4_K_M, API http://127.0.0.1:18767. Панель автоматически запускает установленный сервер, если он выключен; автозапуска Windows нет. Лимита запросов сервиса нет, скорость зависит от компьютера. Модель предлагает темы, результат показывается до применения. Сверка слов со сценарием выполняется отдельным алгоритмом.

На текущем компьютере проверены настоящий WAV и MP4, отмена во время распознавания и полный путь из CEP до 34 клипов Premiere. Нужен ручной контроль имён, пунктуации и синхронизации: локальное распознавание может ошибаться. Путь к модели передаётся относительно её папки, поскольку выбранная Windows-сборка Whisper не читает кириллический абсолютный путь модели. Пути временных заданий с кириллицей в имени пользователя отдельно не проверены.
