# SS-ART-001 — первый native-этап, не художественная приёмка

Premiere-SS-ART-001-written.mp4: настоящие 126 экспортированных кадров Premiere, 1080×1920/30 fps, три разных этюда по 1.2 секунды с паузами между ними. A: Bebas снизу, Christopher после него. B: жёлтый Christopher первым, Bebas снизу позже. C: красный Bebas и встречное раскрытие Christopher. Размеры берутся из принятой 063; обычная речь не менялась.

Compare-A/B/C.mp4: слева рилс с 4/24/19 секунды, справа этюд. Выбор эпизодов документирован, но начало анимаций ещё не синхронизировано точно. Отличия композиции/масштаба/темпа остаются предметом следующей доводки; эти файлы не подтверждают сходство с референсом.

native.txt — 1080 чтений AE-свойств и точный readback буквальных выражений. premiere-pixel-proof.json — проверка реальных PNG: у всех трёх клипов неподвижная пауза чтения на 19 кадрах и меняющийся вход. data-preservation-summary.json — 103 cues полностью совпадают с прежней резервной копией; пять исходных секвенций сохранены. Ранее созданный полный QA-набор 063 сейчас не найден в открытом проекте; его текущая сохранность этим этапом не подтверждена. Исполнитель его не удалял.

Новые этюды не установлены как runtime; только отдельная тестовая секвенция c4f43473-d57d-4153-a868-997826aacd63. Открыты короткие/длинные тексты, адаптивный темп, весь контур безопасности с blur, полноценная художественная оценка и интеграция. Маска не является настоящей прорисовкой рукописных штрихов.
