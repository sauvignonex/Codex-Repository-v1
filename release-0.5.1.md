# Версия 0.5.1 — распознавание выделенного аудиоклипа

Исправлена ошибка `(var).join is not a function`: CEP showOpenDialog ожидает массив расширений, прежний код передавал строку. Регрессионная проверка проверяет реальный контракт аргументов.

Главная кнопка «Распознать» сначала читает выделенный аудиоклип активной секвенции. При одном выделенном клипе распознаёт его исходный файл только в пределах inPoint/duration; словесные тайминги сдвигаются на start клипа. Если ничего не выделено, открывается выбор файла. Выбор другого файла всегда доступен в свёрнутых настройках. Несколько аудиоклипов, вложенные/отсутствующие медиа, реверс или изменённая скорость дают понятное сообщение без неверного распознавания.

Для клипа с обрезкой сохраняется отдельный preview.wav и его положение. При создании новой секвенции звук проверки добавляется в соответствующее место. Старый формат sourceMedia — строка пути — продолжает работать. Промежуточный audio.wav удаляется, preview.wav хранится пока нужен документу; папку задания не удалять до завершения работы с ним. Распознаётся исходный звук файла, эффекты, микшер и автоматизация громкости на таймлайне в него не входят.

Предупреждение о низкой уверенности теперь перечисляет конкретные слова вместо одинакового сообщения для каждой фразы. Оно не означает сбой, но имена и неизвестные слова действительно требуют сверки на слух или со сценарием.

## Проверено

Нажата основная кнопка настоящей CEP-панели на выделенном пользователем аудиоклипе активной секвенции «Вертикальный шаблон»: распознаны 34 фразы; существующий документ и монтаж не заменены. Новый результат оставлен в проверке фраз. Отдельная проверка распознала 7 секунд исходного файла начиная с 20-й секунды, сдвинула все слова на 15-ю секунду таймлайна и сохранила 7-секундный preview.wav.
